# Google Docs - Collaborative Documentation

## Introduction
Google Docs is an online word-processing tool used to create, edit, format, and share documents.

## Features of Google Docs
- Real-time collaboration.
- Sharing documents with different access permissions.
- Comments and suggestions.
- Version history.
- Formatting using headings, styles, tables, and images.
- Automatic saving to Google Drive.

## Concepts Learned
1. Creating and formatting documents.
2. Using headings and styles.
3. Inserting tables and images.
4. Creating a table of contents.
5. Using comments and suggestions.
6. Sharing documents with collaborators.
7. Viewing and restoring previous versions.

## Advantages
- Accessible from anywhere with an internet connection.
- Multiple users can work simultaneously.
- Changes are saved automatically.
- Easy sharing and collaboration.

## Learning Outcome
Learned how to create professional documents and collaborate effectively using Google Docs.
