
# LaTeX – Technical Documentation

## 1. Introduction

LaTeX is a document preparation system used to create
professional technical documents, research papers,
academic reports, and scientific publications.

It provides precise control over document formatting
through commands and environments.

## 2. Concepts Learned

The following concepts were explored:

- Document classes and document structure
- Packages and preamble
- Sections and subsections
- Text formatting
- Ordered and unordered lists
- Mathematical equations
- Tables and figures
- Captions and labels
- Cross-referencing
- Bibliography and citations

## 3. Practical Implementation

A technical report titled "Technical Documentation
Using LaTeX" was created as a practical exercise.

The report demonstrates:
- Title page and abstract
- Automatic table of contents
- Mathematical expressions
- Tables and figures
- References and bibliography
- Headers, footers and page numbering

## 4. Files Included

| File | Purpose |
|---|---|
| LaTeX_Report.tex | Original LaTeX source code |
| LaTeX_Report.pdf | Compiled technical report |
| README.md | Documentation of concepts learned |

## 5. Compilation Process

The report was written using LaTeX and compiled
using Overleaf.

The compilation process converts the source file
into a properly formatted PDF document.

## 6. Learning Outcome

Through this practical exercise, I learned how to
structure technical documents, use LaTeX commands,
format mathematical expressions, create tables,
and generate professional PDF reports.
