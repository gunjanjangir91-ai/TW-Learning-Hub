
# Beamer – Presentation Documentation

## 1. Introduction

Beamer is a LaTeX document class used to create
professional presentations in PDF format.

It provides structured slide layouts and allows
the use of mathematical expressions, tables,
images, blocks and different themes.

## 2. Concepts Learned

- Beamer document class
- Presentation themes
- Title and agenda slides
- Frames and sections
- Blocks and example blocks
- Columns and layouts
- Mathematical expressions
- Tables and slide numbering
- Color customization

## 3. Practical Implementation

A presentation titled "Technical Writing: From
Documentation to Collaboration" was created.

It explains the six major tools covered in
the Technical Writing course.

## 4. Important Commands

| Command | Purpose |
|---|---|
| \begin{frame} | Starts a slide |
| \end{frame} | Ends a slide |
| \title{} | Defines presentation title |
| \author{} | Defines author |
| \usetheme{} | Selects a theme |
| \tableofcontents | Creates an agenda |
| \section{} | Defines a section |
| \begin{columns} | Creates multiple columns |

## 5. Compilation

The presentation was written in LaTeX using
the Beamer document class and compiled using
Overleaf to generate a PDF.

## 6. Learning Outcome

This exercise provided practical experience
in designing structured presentations using
Beamer, applying themes, arranging slide
content and formatting mathematical expressions.
