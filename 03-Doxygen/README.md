# Doxygen - Student Management System

## Introduction
Doxygen is a documentation generation tool that automatically creates software documentation from specially formatted comments in source code.

## Project Description
This project demonstrates how Doxygen generates documentation for a C++ Student Management System.

## Concepts Learned
- Writing documentation comments.
- Using @brief to describe functions and classes.
- Using @param to document function parameters.
- Using @return to describe return values.
- Generating HTML documentation using Doxygen.

## Project Files
- main.cpp - C++ source code.
- Doxyfile - Doxygen configuration file.
- generated-docs/ - Generated documentation.

## Steps to Generate Documentation
1. Install Doxygen.
2. Add Doxygen comments to the C++ source code.
3. Generate the configuration file using `doxygen -g Doxyfile`.
4. Configure the Doxyfile.
5. Run `doxygen Doxyfile`.
6. Open `generated-docs/html/index.html` in a browser.

## Output
Doxygen successfully generated an HTML documentation website for the Student Management System.

## Learning Outcome
Learned how to create structured and professional code documentation automatically using Doxygen.
